## 🌟 About The Project

**Vehicle Rental System** is a simple Python-based console application created to manage vehicle rentals in an easy and organized way.

The project allows users to view available vehicles, select a vehicle for rental, enter the rental duration, and calculate the total rental cost. It is designed as a practical assignment to understand how basic Python programming concepts can be used to create a real-world application. 🚀

## 💡 How It Works

The basic working flow of the project is:

```text
👤 User
   ↓
📋 View Vehicles
   ↓
🚘 Select Vehicle
   ↓
📅 Enter Rental Days
   ↓
💰 Calculate Total Rent
   ↓
🧾 Display Rental Details
```

### 💰 Rent Formula

**Total Rent = Rental Price per Day × Number of Days**

For example:

```text
GT 350 = ₹2,000 per day
Rental Duration = 3 days

Total Rent = 2,000 × 3
           = ₹6,000
```
